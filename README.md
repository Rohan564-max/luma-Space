# Rohan Das Portfolio

A portfolio website for Rohan Das, showcasing work in creative technology, WebGL, shaders, 3D, and interactive experiences.

## Structure

- `index.html`: Main HTML file
- `css/`: Stylesheets
- `js/`: JavaScript files
- `libs/`: Libraries
- `assets/`: Images and assets
- `data/`: Data files

## Setup

Open `index.html` in a web browser to view the site.

Note: This is a basic structure. Add content to the CSS, JS, and assets folders to make the site functional.
